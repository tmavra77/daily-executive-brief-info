Personal automation

A clear view of the day ahead.

Daily Executive Brief combines the owner's Notion tasks and primary Google Calendar into one morning email.

The brief covers today's commitments, actionable tasks due today or overdue, and the following seven days. It highlights priorities and a few attention points supported by the source data.

How it works

  • Reads the owner's configured Notion task database.
  • Reads events from the owner's primary Google Calendar.
  • Builds an HTML email with a plain-text alternative, using fixed rules.
  • Sends the brief through the owner's Gmail account to the same owner's fixed Gmail address.
This is an owner-operated personal utility. It has no public sign-up, paid subscription, advertising or AI processing.

Google access

The utility requests Calendar event read permission and Gmail send permission. The supplied implementation reads the primary calendar only and sends the completed brief. It does not request Gmail read permission.

Scheduled execution uses GitHub Actions, with a target delivery time of approximately 06:10 Europe/Athens. Local previews are also available to the owner.
